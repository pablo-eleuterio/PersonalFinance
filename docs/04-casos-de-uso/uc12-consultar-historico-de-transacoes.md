# UC12 - Consultar Histórico de Transações

## Objetivo
Permitir que o usuário consulte seu histórico de transações.

## Ator Principal
Usuário.

## Pré-condições
1. O usuário deve estar logado no sistema.

## Gatilho
O usuário acessa a opção de consultar histórico de transações.

## Fluxo Principal
1. O usuário acessa a opção de consultar histórico de transações.
2. O sistema solicita que o usuário informe o período que deseja visualizar.
3. O usuário indica o período.
4. O sistema exibe o histórico de despesas e receitas de acordo com o período informado.

## Pós-condições
1. O usuário visualiza o histórico de transações com sucesso.
