# UC06 - Consultar Despesas Previstas

## Objetivo
Permitir que o usuário consulte uma lista com todas as despesas previstas, de acordo com o período selecionado.

## Ator Principal
Usuário.

## Pré-condições
1. O usuário deve estar logado no sistema.

## Gatilho
O usuário acessa a opção de consultar despesas previstas.

## Fluxo Principal
1. O usuário acessa a opção de consultar despesas previstas.
2. O sistema solicita o período da consulta.
3. O usuário informa o período.
4. O sistema exibe a lista com todas as despesas previstas para aquele período.
5. O sistema exibe o valor total das despesas previstas nesse período.

## Pós-condições
O usuário visualiza as despesas previstas e o valor total referente ao período selecionado.
