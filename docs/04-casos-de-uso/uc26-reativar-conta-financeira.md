# UC26 - Reativar Conta Financeira

## Objetivo
Permitir que o usuário reative uma conta financeira anteriormente desativada.

## Ator Principal
Usuário.

## Pré-condições
1. O usuário deve estar logado no sistema.
2. O usuário deve possuir ao menos uma conta financeira desativada.

## Gatilho
O usuário acessa a opção de contas desativadas.

## Fluxo Principal
1. O usuário acessa a opção de contas desativadas.
2. O sistema exibe as contas financeiras desativadas do usuário.
3. O usuário seleciona a opção de reativar uma conta.
4. O sistema solicita a confirmação da reativação.
5. O usuário confirma a reativação.
6. O sistema reativa a conta financeira.
7. O sistema informa que a conta foi reativada com sucesso.

## Pós-condições
1. A conta financeira está ativa novamente e disponível para novas movimentações.
2. O saldo da conta volta a ser considerado no cálculo do saldo consolidado.
