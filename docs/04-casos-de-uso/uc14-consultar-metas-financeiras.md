# UC14 -  Consultar Metas Financeiras

## Objetivo
Permitir que o usuário acompanhe as suas metas financeiras.

## Ator Principal
Usuário.

## Pré-condições
1. O usuário deve estar logado no sistema.

## Gatilho
O usuário acessa opção de consultar metas financeiras.

## Fluxo Principal
1. O usuário acessa opção de consultar metas financeiras.
2. O sistema exibe as metas financeiras cadastradas, apresentando o nome, o valor objetivo, o valor reservado e o progresso de cada meta.
3. O usuário seleciona a opção "Detalhes" de uma meta.
4. O sistema exibe o total reservado na meta e os valores reservados em cada conta financeira de origem.

## Pós-condições
1. O usuário visualiza suas metas financeiras, seus valores e respectivos progressos.
