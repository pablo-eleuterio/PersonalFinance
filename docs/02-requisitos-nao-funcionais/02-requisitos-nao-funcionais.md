# Requisitos Não Funcionais
## RNF01 - Segurança
O sistema deverá armazenar as senhas dos usuários utilizando um algoritmo seguro de hash, garantindo a proteção das credenciais.

## RNF02 - Desempenho
O sistema deverá apresentar desempenho adequado durante sua utilização, evitando atrasos que prejudiquem a experiência do usuário.

## RNF03 - Usabilidade
O sistema deverá possuir uma interface intuitiva e de fácil utilização, permitindo que o usuário realize suas operações sem necessidade de treinamento.

## RNF04 - Compatibilidade
O sistema deverá ser compatível com os principais navegadores modernos, como Google Chrome, Microsoft Edge e Mozilla Firefox, em dispositivos desktop e móveis.

## RNF05 - Disponibilidade
O sistema deverá estar disponível para a utilização durante todo o período de operação, exceto em casos de manutenção programada ou falhas técnicas.

## RNF06 - Backup
O sistema deverá realizar backup periódico dos dados, garantindo sua recuperação em caso de falhas.

## RNF07 - Controle de acesso
O sistema deverá exigir autenticação do usuário para permitir o acesso às informações financeiras.

## RNF08 - Expiração de sessão
O sistema deverá encerrar automaticamente a sessão do usuário após um período de inatividade, exigindo uma nova autenticação para continuar o acesso.
